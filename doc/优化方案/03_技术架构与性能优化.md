**连线三种画法各归一族**（`buildConnectors`）：直角折线（`tree*` / `org*` / `matrix` / `balancedDown` /
竖向时间线的一级分支）、曲线（其余全部，含水平/S 形时间线、鱼骨与绕圈那几码）、
斜线段（`stagger` / `staggerUp`，一条线段从父框穿到子框）。
归族按**几何**不按名字：`balancedDown` 中文名属于"平衡"一族，画出来是两条向下的条带，

测试里的族判定必须**先按码把斜线族摘出去**再筛"没有 C"——交叉树的线同样没有折线检测要的 C，
混进折线检测会把这一族自己判挂（`isSlantFamily`）。
**更要紧的是 `treeTableLeft` / `treeTableTop` 的码名本身就以 `tree` 开头**，
`buildConnectors` 与测试的 `isElbowFamily` 两处 `startsWith("tree")` 启发式都得先按码把表格族摘出去
（`TABLE_LAYOUTS` / `TABLE_CODES`），否则表格两码会一边画出没人要的折线、一边被"连线数 = 主题数-1"判挂。

**主轴（`buildAxis`）**：时间轴四向与鱼骨左右这 6 码另外画一条带箭头的轴（`LayoutResult.axis`），
轴身从中心主题的前缘起、伸过最后一个一级分支的远侧缘 16，末端一个开口箭头（不用 SVG marker，
导出与打印拿的是同一份 path）。S 形时间线**不给轴** —— 它的主轴本身要折返，一条直线盖不住。
画布与 SVG 导出都只读 `layout.axis` 这一份，没有第二条画法。
