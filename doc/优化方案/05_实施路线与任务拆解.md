## 0. 执行者必读红线（家族铁律，违者返工）

1. **同步红线**：绝不从 lead 跑 `sync.py --apply` 到本仓，除非明确带 `--allow-shrink` 决策——
   本仓 `scripts/release.sh`、`install.sh` 比家族模板富（2026-10-08 dry-run 实测会被模板收缩）。
   dry-run 恒安全，apply 前必须停。
2. **CI 红线**：`.github/workflows/` 是本仓自有（lead manifest `custom_ci_workflow: true` 保护中）。
   允许小改（如 T-0-3），**家族 CI 模板永不得覆盖**；每处 CI 改动在 07 记一笔。
3. **发布红线**：release / push tag / npm publish 都是对外不可逆动作，**必须用户点头**才执行。
   版本基线 = max(package.json, Cargo.toml, tauri.conf.json, 最高 v* tag)（release.sh 已内置，别绕过它手动打 tag）。
4. **测试红线**：测试 runner 是自研零依赖方案（`node tests/run.mjs`，esbuild 逐文件打包，terminal 同款），
   **不引入 vitest/jest**；新增 `tests/*.test.ts` 会被 runner 自动枚举，无需注册。
5. **token 纪律**：`GITHUB_PAT` / `NPM_TOKEN` / `CRATES_IO_TOKEN` 存于 `z-biz-tool-lead/.env`；
   绝不把 token 值写进任何文件、脚本输出或提交信息。
6. **史线**：不 force push、不 amend 已推提交、绝不 `push origin --delete main`。
7. **数字纪律**：本文所有数字是 2026-10-08 现量。动手前先跑 Phase 0，以复跑值为准；
   复跑与本文不符时先查环境（node 版本、浅 clone、脏工作区），再怀疑文档。
8. **环境**：本机 macOS + node v22（**Node 21+ 自带全局 `navigator`**，mac 上 `navigator.platform === "MacIntel"`
   ——这是 A-01 的根源，写测试断言要显式传平台参数，别依赖"node 没有 navigator"的旧假设）；
   macOS 无 GNU `timeout` 命令，批处理别用它。

## 阶段 P4 · 契约门与两侧口径对齐（2026-10-25 立项）

> 起因：**家族扫描**（z-biz-tool-lead 的家族探针）报「mind 有 2 个事件发了没人收」
> （Rust emit `autosave-fired` / `emmx-saved`，前端只 listen `open-path`）。
> **探针报错了** —— mind 的前端**确实在听**这两个事件：
> [src/stores/recentStore.ts](../../src/stores/recentStore.ts) 把事件名放进常量表 `pairs`，
> 再由 `for (const [name, handler] of pairs)` 解构出来喂给 `listen(name, …)`；
> 探针只认 `listen("字面量")` ⇒ **漏扫**。
> ⇒ **探针自己错了要改探针**（修在 z-biz-tool-lead 仓），而且
> **本仓自己需要一道能识别转接的门** —— note/box 那一版直接搬过来会**误报**。
> 顺带在这条链路上读出**一条真 bug**（列表侧与删除侧各写各的判据），一并办掉。

| 任务 | 内容（文件级） | 前置 | 验收 |
| --- | --- | --- | --- |
| **T-4-1** 「快照」判据两侧对齐 | [src-tauri/src/backup.rs](../../src-tauri/src/backup.rs)：把「扩展名必须是 `.emmx`」抽成**一个**函数 `is_snapshot_file`，`autosave_list`（列表侧）与 `autosave_drop`（删除侧）**共用**它 ⇒ **列表 = 可删 = 计数**；`autosave_clear` 的注释把口径写准（计数是**快照数**，非 `.emmx` 的文件被 `remove_dir_all` 连带带走但不算份数）。**不做**任何保留策略改动（§1.3-18 已裁定「不动自动保存的写入节奏与保留份数」） | 无 | `cargo test --locked --all-targets` 全绿；**变异门**：去掉列表侧的过滤 ⇒ 新增的两条例**同时红**，且失败输出里能直接看到 `.DS_Store` / `.emmx.tmp` 的入列 |
| **T-4-2** IPC 契约门（博采众长） | 新增 [tests/ipcContract.test.ts](../../tests/ipcContract.test.ts)：① 前端 `call()` 的命令后端必须注册；② 后端注册的命令要么被前端调用、要么登记为「预留未接线」；③ **Rust `emit` 的每个事件前端必须 listen**（**含常量表转接**）；④ **反向** —— 前端监听了 Rust 从不发的事件也要报；外加「`backup.rs` 里的 `.emmx` 判据必须只有一处」。**比 note/box 多走一步**：那两仓只认 `listen("字面量")`，本仓要能解析常量表 + `for…of` 解构 | 无 | `node tests/run.mjs` 全绿；**变异门 6 组全杀**（前端少监听 / Rust 改事件名 / Rust 改注册名 / 多写一份判据 / Rust 常量改名 / **把解析器自己改坏** ⇒ 合成样本先红，门禁不会退化成永远绿） |

> 口径纪律（承 P3）：**契约门自己也要能被证伪** —— T-4-2 里那条「把解析器自己改坏」的变异就是干这个的：
