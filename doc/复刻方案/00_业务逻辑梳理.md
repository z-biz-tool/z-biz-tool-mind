## 0.3 核心原则

- **P-1 一份树，六种投影。** 大纲、看板、PPT、甘特、遍历序列、音视频脚本都不是独立数据，是同一棵 `Shape` 树的派生视图。任何"视图里的编辑"都必须回落成树上的操作。复刻时若在视图层存第二份数据，后面每一步都会付利息。
- **P-2 布局是算出来的，不是存出来的。** 节点只存父子关系 + 内容 + 样式引用；`CX/CY/Width/Height` 是布局引擎的输出缓存，不是事实。所以同一棵树能在 18 个结构族之间无损切换。
- **P-3 文本大纲 ⇄ 树 是同构的。** `Enter` 同级、`Tab` 子级、`Shift+Tab` 反缩进这一套输入协议，同时服务于：手工录入、批量添加主题、粘贴 Markdown、OCR 分段插入、AI 生成结果插入、大纲视图编辑。这是最高频的输入路径，必须做成一个原语 `outlineToTree(text) / treeToOutline()`，而不是六处各写一遍。
- **P-4 限额与权益是一等公民。** 免费版/会员/AI 点数/云空间/页面数构成了这个产品的骨架，不是贴上去的皮。功能门控点必须先建出来，否则后面无处插桩。

## 2. 领域模型（.emmx 实证）

### 2.1 容器

`.emmx` = ZIP：`document.xml` + `page/page.xml`（每页一个）+ `theme.xml` + `rels/page_rels.xml` + `media/*`（图片、附件、图标全部内嵌）。文件版本号写在 `<Document Version="7.2">`。

### 2.2 对象层级

```
Document
├── Properties        DocGuid / Creator / CreatedDate / Modifier / ModifiedDate
│                     ScreenWidth·Height / Dpi / Platform / AutoLayout / TimelineWidth / CalloutLayout
├── GanttOption       WorkDay("1;1;1;1;1;0;0") / MajorTick / MinorTick / StartDate·FinishDate
│                     StartTime(28800=8:00) / FinishTime(57600=16:00) / UnitWidth(100)
├── MarkSheet         图标（标记）资源表
└── Page[]            ID / QuickMask(显示层级掩码) / Zoom
    ├── PageProps     Width / Height / CX / CY / ScrollX / ScrollY
    ├── Layout        HSpacing / VSpacing / Layout(结构类型, 实测取值 6|7|8)
    │                 SectorAlign / SubLevel / LayoutDirection / LayoutMemory / AutoLayout
    ├── PrintSetup    纸张 / 方向 / 边距 / FittoSheet / 单位(mm|px|inch|cm)
    ├── Theme →       ThemeColor / ThemeEffect / ThemeText / ThemeShape（四个独立 ID，可混搭）
    └── Shape[]       ← 唯一的内容单元
```

### 2.3 Shape（唯一内容单元）

| 组成 | 字段 | 业务含义 |
| --- | --- | --- |
| 身份 | `Type` + `ID` | 见 2.4 类型表 |
| 树 | `LevelData.Super` = 父 ID | 森林：允许多棵（浮动主题各成根） |
| 几何 | `Transform` CX/CY/X/Y/Width/Height、`Geometries(Geometry: MoveTo/LineTo/CurveTo)` | 缓存坐标 + 实际矢量路径（形状/线条） |
| 富文本 | `TextBlock > Paragraph > Character` | 三层结构：块（换行宽度/对齐）→ 段（项目符号/对齐）→ 字符（粗斜下划删/字号/颜色） |
| 样式 | `ShapeStyle` `StyleMask` `FillFormat` `LineFormat` `TextColors` | `StyleMask` 标记哪些属性被用户显式覆盖，其余继承主题槽位 |
| 颜色引用 | `Color V= Shade= Tint= Ref= ThemeColor=` | 不存死值，存"取 Accent3 再降明度 50%"这类引用 |

### 2.4 Shape 类型（在 5 个真实文档中实测出现）

`MainIdea`（中心主题，**每页有且仅一个**——报错文案「每页只能包含一个中心主题」）· `MainTopic`（一级）· `SubTopic`（二级及以下）· `Floating`（浮动主题，独立根）· `Callout`（标注）· `Boundary`（外框）· `Summary` + `SummaryTopic`（概要 + 概要上的说明主题）· `MMConnector`（父子间连接线）· `RelatConnector`（关系线，跨节点）· `Note` · `Comment` · `Tag` · `Mark` · `Attachment` · `Image` · `Table` · `Task` · `Hyperlink` · `Formula`。

> `MainTopic` / `SubTopic` / `Floating` 是**布局角色**而非语义类型；`Note` / `Tag` / `Image` 等是**挂载部件**。复刻时建议：`NodeType = {idea, topic, subtopic, floating, callout, boundary, summary, summaryTopic}` + `parts: PartBag`（可缺省字段集合）。这两者混在一层里是 MindMaster 字段表看起来杂乱的原因，我们没必要继承这个混乱。

### 2.5 主题体系（4 个可组合子主题）

```
Themes > Theme(ID, Name, Effect, Rainbow)
  ├── ThemeColor   ColorScheme: Accent1..Accent10（10 个色槽）+ 深色/浅色变体
  ├── ThemeEffect  MapEffect: 按层级给 ShapeFormat（QuickMask 掩码选择作用范围）
  │                + CircleEffect / BubbleEffect / FlexoStyle / Toggler
  ├── ThemeText    FontSchemeLst / FontScheme → 每层级 Paragraph+Character 默认值
  └── ThemeShape   ShapeScheme → 每层级形状几何（圆角 Rounding、边框 LineWeight）
```

`Rainbow`（彩虹色）是一个开关：打开时层级颜色从 Accent 序列循环取；关掉退化为单色。另有「对称色」「交替色」两种取色策略。

**派生规则**：新建文档取 `DefaultTheme=40`；用户可「提取当前文档主题」存为自定义主题；自定义主题可自动同步到个人云跨设备使用；可对单个节点覆盖（`StyleMask`），覆盖可被「主题应用时：保留自定义设置 / 覆盖自定义设置」二选一策略处理。

## 3. 功能域业务规则

### 3.1 节点树编辑（键盘是第一公民）

| 键 | 语义 |
| --- | --- |
| `Tab` / `Insert` / `Ctrl+Enter` | 插入子主题 |
| `Enter` | 在选中主题**之后**插入同级 |
| `Shift+Enter` | 在**之前**插入同级 |
| `Shift+Insert` | 插入父主题（整棵子树降一层） |
| `Delete` | 删除主题（连带子树）；外框/标注/概要被选中时按 Delete 移除 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做，级数默认 **60**，可配 |
| `Ctrl+Tab` | 切换文档 |
| `F5` | 全屏遍历主题 |
| `Ctrl+Q` | 亿图 AI 面板 |
| `Ctrl+F9` | 收集创意（头脑风暴） |
| `Ctrl+P` / `Ctrl+E` / `Ctrl+L` / `Ctrl+A` | 彩色铅笔 / 橡皮擦 / 激光笔 / 默认光标 |
| `Ctrl+D` | 注释内插入日期时间 |
| `Ctrl+Shift+L` | 公式编辑器 |
| `Ctrl+Shift+.` / `,` | 增大 / 减小字号 |
| `@` 或 `[[` | 编辑态唤起双向链接节点联想 |
| `Shift`（拖动时按住） | 临时开关主题吸附 |

批量录入：`添加多个主题` 对话框，规则=「每行一个主题，`Tab` 缩进一级，`Shift+Tab` 上升一级」。同一规则复用于 OCR 分段插入子主题、Markdown 导入、AI 生成内容插入。

粘贴有 4 个可配行为维度：外部文本入导图（粘贴到当前主题 / 粘贴到子主题 / 纯文本 / 保留源格式 / 保持原有格式 / 选择性粘贴每次都弹框）、图片粘贴默认落点（主题内 / 页面背景 / 子主题且不带默认文字）、注释内粘贴、选择性粘贴对话框（保留源格式 / 仅文本 / 无格式文本-分离段落）。

选中语义丰富：全选主题 / 所有同级 / 所有父级 / 所有浮动 / 所有标注 / 所有外框 / 所有概要 / 所有概要上的主题 / 所有关系线 / 当前分支 / 下一层级 / 相同类型 / 反向选择。业务含义 = **批量操作的作用域选择器**，不是"选中节点"这一个概念。

### 3.2 层级呈现与聚焦

`QuickMask` 显示层级 1–9 / 所有层；折叠全部、展开全部、主分支一键折叠；**"每次只展开一层"**（配合 `LayoutMemory` 记住展开态）；下钻（仅看本分支）/ 上钻（还原）；聚焦；适应窗口大小 / 适应窗口宽度；视图导航小地图（点击定位）。

特殊布局下存在"因布局效果被隐藏的节点"，导航时不可跳转——业务上意味着**可见性是布局的函数**，导航器必须查询布局结果而非直接查树。

### 3.3 结构族（布局类型，≥18 族 / 约 35 变体）

| 族 | 变体 |
| --- | --- |
| 逻辑图（思维导图） | 向左 / 向右 / 双向平衡 / 平衡向下 / 顺时针 / 逆时针 |
| 括号图 | 左 / 右 |
| 鱼骨图 | 左 / 右 |
| 组织结构图 | 向上 / 向下 / 上下双向 |
| 树状图 | 左上 / 右上 / 左下 / 右下 / 向上对称 / 向下对称 |
| 时间轴 | 向上 / 向下 / 向左 / 向右 / S 形（回转宽度可配 `TimelineWidth`） |
| 交叉树 | 向上 / 向下 |
| 放射 · 扇形放射 · 气泡图 · 圆形图(Circle Packing) · 矩阵图 · 自由布局 | — |
| 树形表格 | 左侧标题 / 顶部标题 |

每族带参数：`HSpacing` `VSpacing`（默认 30/30）`SectorAlign` `SubLevel` `LayoutDirection` `AutoLayout`；还有全局开关「标注是否参与布局」「组织结构布局模式」「主题层叠」「分支自由布局（允许自由移动二级主题分支线）」「同级主题对齐」。

### 3.4 样式与美化

- 四级入口：主题风格（整套）→ 主题颜色（10 Accent）→ 主题字体 → 单节点形状格式。
- 填充：单色 / 渐变（线性·放射·矩形，多 stop，可设 Shade/Tint 与透明度）/ 纹理 / 图案填充（前景+背景）/ 无。
- 线条：实线 / 虚线 / 渐变线 / 无；起点·终点箭头类型与大小（极小→巨大 6 档 + 自定义）；线头（平/圆/方）；线宽；圆角（预设 + 数值）。
- 阴影：无 / 内部 / 外部 / 透视，角度·模糊·XY 偏移·透明度·颜色。
- 文本：字体·字号·颜色·高亮·粗斜下划删·上下标·对齐（左中右两端）·项目符号·缩进·**文字跟随路径**（路径上方/中间/下方）。
- 布局尺寸类：主题文本宽度（换行宽度）、主题边距（上/下/左/右，可按「选中主题 / 全部 / 页面内所有同类型」批量应用）。
- 手绘风：铅笔 / 炭笔 / 水彩笔 / 马克笔 / 油漆桶 + 全局手绘设置 + 魔法手绘。
- 页面：背景色 / 背景图（图库 + 自带）/ 背景纹理 / 移除背景 / 插入图片显示在文字（上方/下方/沉底）；皮肤 浅色·深色·暗黑。
- 动效：添加主题 / 切换布局的动画开关。

### 3.6 大纲视图

同树投影。右侧面板可设：常规模式 / 纸张模式（+纸张透明度）、大纲宽度（窄屏/宽屏）、背景（无/单色/渐变/图片 + 高斯模糊）。支持编辑（缩进、粗斜下划、设为待办 `alt+1`、下钻）、查找替换、导出大纲（PDF/图片/Word 等）。
**明示风险**：含双向链接的文件在大纲模式编辑相关主题可能导致链接失效 → 复刻时需要一个"降级警告"门控。

### 3.7 看板视图（= 完整的项目任务管理，非玩具）

- 结构：列（`KBCol`）× 卡片（`KBCard`），卡片与主题一一映射（任务属性挂在主题上）。
- 卡片元素：标题 / 待办 / 优先级 / 进度% / 任务时间 / 标签 / 注释 / 图片 / 附件 / 超链接；**显示元素可逐项开关**；字号可配。
- 卡片菜单：设置待办、取消待办、优先级、进度、任务时间、标签、图片、附件、卡片颜色、复制/剪切/粘贴、新建卡片、删除。
- 列菜单：整列颜色、复制列、删除列。
- 筛选（多条件）：内容包含/不包含；截止日期 早于/晚于/相等/为空/不为空/今天/明天/昨天；元素（附件·超链接·注释·图片 有无）；标签 包含/不包含/为空/不为空。
- 排序：卡片标题 / 截止日期 / 优先级 / 日程计划，可加多条件。
- 风格：看板风格、配色方案（单色/渐变/彩虹/交替）、卡片样式、明信片样式、背景（色/图/透明度）、简易模式、看板模板（在线模板中心）。
- 缩放 25–400%。

### 3.8 PPT / 演说视图

- 生成路径 4 条：从主题创建（1 主题 → 1 页）· 自动创建整套 · AI 一句话/长文本/导入文件 → **先产出可编辑大纲** → 选风格 → 生成 · 单页 PPT（选中主题或输入描述）。
- 幻灯片管理：新建/重命名/删除/上移/下移/隐藏幻灯片/删除整个幻灯片组/从当前页播放。
- 放映：全屏播放器（`EDPlaySlideView`）、每页时长、动画演说、演说风格模板（AI 生成演讲方案 / 已有脑图转演讲 / 转化演讲模式）。

### 5.1 画布方案取舍（需要用户拍板的一项）

MindMaster 是 Qt 自绘。在 Tauri 里复刻有三条路：

| 方案 | 优点 | 代价 | 建议 |
| --- | --- | --- | --- |
| **SVG（推荐）** | 与 .emmx 的 `Geometries` 路径模型天然对应；DOM 命中测试/焦点/无障碍/文本换行/图片全免费；导出 SVG 直接序列化 DOM；调试可视化 | 节点 >3000 时性能下滑 | P0–P1 用它，先拿到正确性 |
| Canvas 2D | 万级节点可控 | 命中测试、文本排版、光标、导出全要自己写 | 仅在压测不达标时切 |
| WebGL（Pixi/自研） | 上限最高 | 富文本排版成本极高，与"文本即树"的主路径冲突 | 不做 |

决策依据：本产品单页节点量级通常在几十~几百，超 1000 官方自己都在告警。SVG 的正确性收益远大于性能风险。若后续要「一屏 5000 节点」再引入 Canvas 后端，布局引擎与选择模型不变（P-1/P-2 保证了这点）。

### 5.3 为什么"业务逻辑"和"技术栈"能对上

- P-1（一份树六种投影）→ `model/` + `engine/` 与 `views/` 严格分层，视图零存储。
- P-2（布局是算的）→ `engine/layout/*` 是纯函数，正好是 `tests/layout-*.test.ts` 最该测的对象（参考仓库把 commandGuard/reconnectPolicy 这类纯决策逻辑放 utils 单测，同一条判据）。
- P-3（大纲⇄树同构）→ `engine/outline.ts` 一个原语，六处复用；也是最容易写判定矩阵测试的模块。
- P-4（限额一等公民）→ `src/utils/entitlement.ts` 单点门控（参考仓库的 `commandGate.ts`/`inputGuard.ts` 就是这个位置的东西）。
- 文件与备份的可靠性 → 直接继承参考仓库的 备份 10 份 + tmp/rename + 0600 + `paths.rs` 白名单（拒 `..`、canonicalize 后 starts_with）。

## 8. 研究方法备忘（避免重复踩坑）

- 用 Win32 + UIA + PowerShell 步骤 DSL 驱动 MindMaster 截图与 dump（`_research/mm.ps1`，支持 `shot/dump/key/raise/click/pat/xy/dbl` 等指令）。
- **该应用会过滤注入式鼠标点击**：`SetCursorPos` 有效（会触发 hover 高亮），但 `SendInput` 的 LEFTDOWN/LEFTUP 无论是否分离、是否加 dwell 均不产生点击效果——与它自己的「禁止虚拟按键」检测逻辑一致。**键盘注入有效**（`Ctrl+N` 成功新建文档）。所以自动化路径应以键盘命令为主，界面探索靠 UIA 树 + 截图，而非逐个点按钮。
- 结论性更强的路径是不碰 UI：`.emmx` 结构 + `settings.xml` + `cn.qm` 全量文案。三者合起来给了字段名、默认值、限额数字、命令全集，比截图可靠。
- 解析 `.qm` 注意：它是 **Qt .qm v2**，字符串是长度前缀 + **UTF-8**，而译文是 **UTF-16BE**。按 UTF-16LE 解会得到 `䵡楮潷` 这类假中文（其实是 "MainWi" 的字节序反了）。
